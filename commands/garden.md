做一次记忆库体检。**默认只报告，不修改任何文件。**

1. 加载 `save-memory` 技能：读它的 `SKILL.md`，拿到本机的 `<引擎>` 路径与记忆目录。
2. 按 `workflows/garden.md` 执行：先跑 `check`（红链 / 跨目录 / 可疑别名）和 `validate`（frontmatter / 文件名 / 编码），再人工判断薄笔记、同义 tags、超载域笔记、长期零召回。
3. 零召回的笔记先跑 `find <它应该被哪些词召回>` 确认是真检索不到，还是「没人问过这类问题」再下结论。
4. 按「问题类型 / 涉及笔记 / 建议动作」三列输出清单。
5. 用户逐条确认后才动手，且只作用于记忆目录；修完再跑一次 `check` 与 `validate`。
