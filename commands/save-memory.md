把这次对话里值得留存的经验写进记忆库。**流程只有一份**，按下面的入口执行，不要凭记忆自己编一套。

1. 加载 `save-memory` 技能：读它的 `SKILL.md`，拿到本机的 `<引擎>` 路径、记忆目录与硬性约束。
2. 严格按 `workflows/extract.md` 执行：五类白名单 → 输出提取审计表 → `find` 检索已有笔记 → 合并判定 → 写入。
3. 写完立刻跑 `check-links <刚写的笔记>` 和 `validate --note <刚写的文件>`；红了当次改掉再汇报，不要把问题留给下一轮。
4. 只写入记忆目录（含素材目录）；key / 密码 / token / 内网地址永不写入。
5. 用户补充要求（有冲突时以它为准）：$ARGUMENTS
