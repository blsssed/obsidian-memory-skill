# 笔记模板（note-template）

`/save-memory` 第 4 步使用。所有写入 `AI记忆/` 的笔记必须遵循本模板。

## 文件名规则

格式：`<主题名>.md`（**不带日期前缀**——主题笔记应当随时间生长，同主题追加而不是堆日期文件）

- 主题名用一句话名词短语，如 `MCP架构认知.md`、`Windows路径坑.md`
- 清洗 Windows 非法字符：`\ / : * ? " < > |` → 删除或替换为 `-`
- 长度 ≤ 50 字符；避免纯数字开头（部分工具排序问题）
- 编码一律 UTF-8（无 BOM）

## Frontmatter 模板

```yaml
---
tags: [2~5 个主题词, 小写, 中英不限]
source: claude-code
created: YYYY-MM-DD
updated: YYYY-MM-DD
related: ["[[相关笔记名]]"]        # 可选，泛相关
solved_by: "[[解法笔记名]]"        # 可选，本笔记是问题时用
supersedes: "[[被取代的旧笔记]]"   # 可选，本笔记取代了谁
part_of: "[[所属主题MOC]]"        # 可选
---
```

- `created` 首次写入时设置，此后不改；`updated` 每次追加/修改时更新
- 类型化边仅在语义真实成立时添加，**宁缺毋滥**；值必须是真实存在的笔记名（写入前用 Glob 验证）

## 正文模板（新建时）

```markdown
# <主题名>

## 一句话结论
<这条知识最精炼的表述，先给结论>

## 详情
<展开：背景 / 过程 / 证据。踩坑类必须包含「现象 → 根因 → 解法」三段>

## 相关
- 详见 [[相关笔记]]（<一句话说明关系>）

---
*来源：Claude Code 对话总结 · 首次记录 YYYY-MM-DD*
```

## 追加时（已有笔记）

- 新知识追加到 `## 详情` 末尾，用 `### YYYY-MM-DD 补充` 小节隔开
- 若新内容修正了正文中的旧结论：旧结论保留但加删除线或标注 `> ⚠️ 已被修正（见下方 YYYY-MM-DD 补充）`
- 同步更新 frontmatter 的 `updated` 和（如需）`tags`
- **不重写用户已有正文**，只追加和标注
