# 流程：总结并写入（save-memory）

用户要求"保存记忆 / 总结对话 / 写入笔记"时加载本文件。严格按顺序执行。

> `<引擎>` 指本 skill 目录下的 `engine/mem.py`。所有命令都形如
> `py -3 <skill目录>/engine/mem.py <子命令>`。

## 1. 提取

读取 [../references/extraction-rules.md](../references/extraction-rules.md)，从当前对话上下文提取五类知识。

- 白名单是**封闭世界**：情境理由（用户在备考等）不构成提取依据
- 唯一例外是用户显式要求保存，此时 frontmatter 标注 `source: user-requested`
- 提取后**必须先输出提取审计表**（候选知识 / 命中类目编号 / 判定理由），类目为「无」的丢弃
- 若没有任何候选命中，明确告知用户「本次对话没有值得保存的内容」，到此结束

## 2. 检索已有笔记

先用引擎定位同主题笔记，跨宿主一致、零依赖：

```
py -3 <引擎> find <主题词1> <主题词2> ...
```

输出每篇的得分 / 标题 / 相对路径。需要看正文时直接读对应文件。

宿主没有命令执行能力时，退化为用文件搜索工具在 `<记忆目录>` 下按主题词、tags、标题各搜一遍。

双链目标可以是用户笔记（标题须来自对话上下文），但**不为寻找建链目标扫描 vault 其他目录**。

## 3. 合并判定

读取 [../references/merge-rules.md](../references/merge-rules.md)，对每条提取出的知识判定走哪条路径（新建 / 域级合并 / 追加 / 标注取代）。

## 4. 写入

读取 [../references/note-template.md](../references/note-template.md)，按模板生成或更新笔记。

- 超过 10 行的代码/配置**外置到 `<素材目录>/`**，正文只留链接和一两行经验
- 双链用裸目标名（`[[目标名]]`）；别名仅当与目标语义一致时才写（如 `[[Spring Cloud 微服务|Eureka]]` 这类真实别称）
- 链接只写在记忆笔记一侧，不修改用户笔记

写盘后跑两条自检，**检出问题当次修复后再汇报**：

```
py -3 <引擎> check-links <刚写的笔记名...>      # 双链目标是否真实存在
py -3 <引擎> validate --note <刚写的文件路径>   # frontmatter / 文件名 / 编码
```

`check-links` 的退出码非 0 表示有红链，必须补链或改名后再交差。

## 5. 汇报

向用户列出本次新建了哪些笔记、更新了哪些笔记、建立了哪些链接（含外置的 snippet），一句话说明每条知识的去向。
