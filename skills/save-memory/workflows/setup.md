# 流程：一次性配置

只在首次安装、换 vault、或引擎提示「未配置 vault」时执行。属于低频动作。

> `<引擎>` 指本 skill 目录下的 `engine/mem.py`。

## 1. 检查现状

```
py -3 <引擎> brief
```

能正常列出记忆索引 = 配置有效，汇报现状后结束。

提示「未配置 vault」时，它会打印配置文件应该写到哪个路径（取决于状态目录）。

## 2. 询问 vault 路径

让用户贴 Obsidian vault 的**绝对路径**，用文件搜索工具验证目录真实存在；不存在就重新询问，不要猜。

## 3. 确认目录名

记忆目录默认 `AI记忆`，素材目录默认 `snippets`。用户没意见就用默认，不要多问。

## 4. 写配置

写到引擎打印的候选路径，UTF-8 无 BOM：

```json
{
  "vault": "<Obsidian 仓库绝对路径>",
  "memory_dir": "AI记忆",
  "snippet_dir": "snippets"
}
```

## 5. 验证

```
py -3 <引擎> build
```

能扫到笔记数即成功。0 篇也算成功——说明 vault 里还没有记忆目录，正常。

## 6. 汇报

告诉用户：配置文件位置、扫到的笔记数、下一步怎么用（第一次「保存记忆」或「召回」）。
